# gmail-cleanup v0.2｜信箱整理清潔｜2026-10-30
來源：MIKO 2026-10-20 陳述的規則（逐條保留，不擴權）；v0.2 併入 H-06 審查的邊界細節（N25），並對齊正本 §7 刪除規則。

## 1. 模式
- 只詢問或盤點 → 唯讀，不移動、不改標籤、不改已讀狀態。
- 重要信檢查（使用者要的節奏是每天早晚；排程另行設定，本 Skill 不自行新增排程）→ 唯讀，列出帳單到期、扣款失敗、補件、工作往來四類，附寄件者、日期、需要的動作。
- 清理 → 依 §2 判定，符合才移到垃圾桶；每批完成後回報移動清單。

## 2. 清理判定（全部成立才移）
1. 寄送時間超過三個曆月：以台北時間計算截止日（例：今天 10/23 → 截止 7/23），不得簡化成 90 天。月份沒有那一天時夾到該月最後一天（例：今天 5/31 → 截止 2/28，閏年 2/29）；截止日當天寄的信保留。
2. 逐封讀內文，確認是純行銷廣告，而且內容已過期。促銷內容夾帶交易、帳單、點數或仍有效票券的保留；附件沒讀到的保留。
3. 以單封郵件判定，不連帶整串。工具只能整串操作時，整串每一封都符合才動，否則保留。
4. 不確定就保留。
5. 動手前再讀一次確認；移動後逐封讀回；結果不明先讀回查證，不盲目重試。讀回發現搬錯就立刻從垃圾桶移回原處並回報；該搬沒搬到的列出來，下一批再處理。

## 3. 一律保留
帳單、付款、收據、發票、交易通知；訂單、物流、退款、保固；保險、貸款、投資、稅務、合約；工作與真人往來；待辦事項；安全通知；仍有效的優惠、點數、票券；星號、重要、已寄出、草稿。

## 4. 不做的刪除
Gmail 的垃圾桶就是它的 _to_delete（MIKO 2026-10-20 指定「清理移到垃圾桶」）。清空垃圾桶或永久刪除：不執行，只列出精確清單，由 MIKO 自己操作（正本 §7：當次指示也不改成永久刪除）。垃圾桶約 30 天後自動清除，所以每批移動清單都要回報。

## 5. 禁止
自行退訂；點擊信中的外部連結；寄信或回信；修改篩選器；新增排程；擴大權限；改變已讀狀態。
