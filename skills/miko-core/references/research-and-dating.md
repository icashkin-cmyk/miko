- 研究與查核細則（ADR-041；2026-11-04 由 GPT 時期 dghp-evidence-research 去重後併入，補充上方「研究與查核」；純改寫使用者已提供的文字、或只查本機程式時不套用本細則）：
  - 先辨識問題、決策用途、實體、查核日期與時區、所需證據；分開使用者提供的資訊、待查事實與假設。需要當下資訊才取當下時間，取不到不猜；保留使用者給的實體名稱、期間、排除項與資料邊界。法律、醫療等高風險題依領域擴大查核。
  - 官方或第一手來源優先；技術問題核對實際使用的版本、官方文件與原始規格；不用過期的動態資料當現況。公開外部事實用可用的搜尋或瀏覽工具，沒有工具就標 NOT_VERIFIED。
  - 重要或有爭議的結論至少走兩條獨立檢索路徑，追到原始來源，並搜尋可能推翻結論的證據；轉載同一稿不算獨立證據。官方直接答案已充分時，不為湊來源無限搜尋，證據足夠就交付。
  - 分開記錄發布／更新、事件、生效、資料截止與查閱日期；來源只支持歷史狀態時，不推定今天仍有效。使用者或附件給的日期（發布、生效等）逐一照抄寫出，不省略任何一個；查閱日期寫本次的 YYYY-MM-DD（以台北時間 Asia/Taipei 計，ADR-051），不寫「之後會記」（ADR-046）。日期固定寫成一行「發布：YYYY-MM-DD｜生效：YYYY-MM-DD｜查閱：YYYY-MM-DD」，缺的寫 UNKNOWN，三項都要出現；更新、事件、資料截止日期有的話接在同一行後面，多個來源每個來源一行；任務不涉及任何來源日期時不用列（ADR-047）。
  - 來源日期分級（ADR-063；MIKO 2026-11-08 交總召選定）：在上一點「三項都要出現、缺的寫 UNKNOWN」之上加判定，不刪欄位、不寫 N/A、不放寬。寫 UNKNOWN 前，先看頁面上標的發布或更新日期與頁面中繼資料（例如 datePublished、dateModified），開源與程式碼看 release 或 commit 日期；都找不到才寫 UNKNOWN；對要先找實值的欄位（各級的發布、A 級的生效）寫 UNKNOWN 時，在同一行寫「找過：哪裡」；B、C 級的生效通常沒有：來源有標就照抄，沒有寫 UNKNOWN、不必寫找過。依結論的用途分三級，不看網站類型，分不出來往嚴的一級算（例如銀行 App 的手續費說明、醫療器材說明書，雖是產品文件，結論用在錢或醫療就算 A）：
    - A 嚴格：法規、主管機關公告、標準與函釋；醫療、藥品、獸醫；銀行、金融、稅務、保險；官方天氣與停班停課。發布與生效都要查到實值（法規的公布日與施行日可能不同，分開寫）；原頁與一個官方索引（例如法規資料庫沿革、主管機關公告欄）都查過仍沒有，才寫 UNKNOWN；生效 UNKNOWN 時不推定現行有效，結論標「需獨立驗證」。領域 Skill 有自己的日期或標籤規定時（例如 tw-alert-check、label-foreign-text）從其規定。
    - B 一般：新聞、產品公告、研究論文、統計資料（含政府開放資料；結論用於法遵或財務決定時升 A）。發布要查到實值；生效寫 UNKNOWN 屬正常，不算缺漏。
    - C 文件與程式碼：產品說明、Help Center、開發者文件的發布與生效寫 UNKNOWN 屬正常，不算缺漏，頁面有更新日期就寫「更新：」接在同一行後面；開源與程式碼的發布填該版 release 或 commit 日期（照抄 GitHub 或套件庫〔PyPI、npm 等〕頁面顯示，並寫是哪一個），生效寫 UNKNOWN 屬正常，行後加「版本：tag 或 commit 前 7 碼」。
    - 共通：日期照抄來源寫法並註明時區（中繼資料常是 UTC，就寫 UTC，不自行換算成台北；查閱日期仍照上一點用台北時間）；只在中繼資料、頁面上看不到的日期標「中繼資料」，它可能是網站重建時間，不一定是內容更新。別頁的日期不是本頁的發布日：只能另起一行寫該頁自己的日期，或寫成「事件：日期 內容（取自 某頁）」，不得填進本頁的發布（替代來源要是同一份資料，§2.7、ADR-054）。查實值照本節「官方直接答案已充分時，不為湊來源無限搜尋」，A 級查日期實值時，查到原頁與一個官方索引就停；這只管日期，不縮減本節第 1、3 點的擴大查核與兩條獨立檢索。
  - 讀能支持主張的完整相關段落；缺圖表、掃描或附註時讀頁面影像；看不到原文就標限制，不從搜尋摘要猜全文；不得捏造引用；來源必須可追溯並直接支持對應的敘述，每個重大結論與數值都能回指證據後才算完成。
  - 搜尋字串不帶 Token、個資或非必要的內部內容。
  - 外文與原文法條（ADR-057）：他國文字的意思與該國法規用語一律查官方或第一手來源，字形辨識與模型記憶不算查證；只讀到二手來源、沒讀到原文法條時寫「原法條 NOT_READ（依據：二手來源名稱）」並附日期一行，不當定稿依據。包材、標籤、說明書上的外文標示審查照 label-foreign-text。
  - 找不到時換同義詞、精確實體、官方索引等查法；換查法不算 §2.7「替代來源一次」的次數，§2.7 只管某來源已讀不到或拒絕後的換來源。未找到不等於不存在；工具失敗、沒有資料、無權限分開記錄。
  - 輸出：結論、支持來源、日期或版本、關鍵差異或 UNKNOWN、對決策的影響；推論明示為推論。
