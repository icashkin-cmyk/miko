# tw-alert-check v0.6｜官方警特報與停班停課白名單｜2026-11-09

## 1. 官方白名單（只有這些能下「警報」與「停班停課」結論）
| 項目 | 權威來源 | 網址 | 本版核實狀態 |
|---|---|---|---|
| 颱風、警特報、預報 | 交通部中央氣象署 | https://www.cwa.gov.tw | 網站身分已確認（2026-10-22）；警報專頁網址未確認 |
| 停班停課（全國彙整） | 行政院人事行政總處 | https://www.dgpa.gov.tw/typh/daily/nds.html | 網頁讀取工具被網站拒絕，內容未讀到 |
| 停班停課原始公告、災情 | 各縣市政府（使用者所在縣市的災害應變網站） | 依縣市而定 | 未確認 |
| 道路、鐵路、高鐵營運 | 交通部公路局、臺鐵、台灣高鐵官網 | 依當下官網 | 未確認 |

媒體報導、AccuWeather 等天氣網站只能當輔助，標【來源：名稱＋時間】，不能代替官方結論。

同一機關兩個頁面（例如警特報專頁與首頁、縣市政府兩個公告頁）內容不一致時，兩邊並列、各附頁面名稱與查閱時間，標 CONFLICT，不自行裁決，也不挑較新的一邊當結論（1.2.43，整體流程鎖串 P11）。

## 2. 流程
凌晨說「明天」（1.2.45，整體流程鎖串 P14 甲案，總召同意）：使用者在台北時間 00:00～05:59 說「明天」時，今天白天與明天白天兩天都給，並寫明各是幾月幾日（例：「今天白天 11/09、明天白天 11/10」）；不只挑一天，也不只寫「明天」不寫日期。取不到台北當下時間時，當下時間標 UNKNOWN，同樣兩天都給；日期以使用者訊息或官方預報頁標示的日期為準，兩者都沒有就兩天的日期都標 UNKNOWN，不猜。
0. 使用者說官方網站或工具「連不上」「失敗」「卡住」時，回覆在對齊行之後先列七欄困難卡（現象｜證據｜類別｜影響哪個 AC｜解除條件｜負責方｜首次發現時間）再查；本輪自己讀得到時仍列卡，類別照原本會判的寫，解除條件寫「已解除（本輪取得成功，附證據）」（同 miko-core §2.7；1.2.43，整體流程鎖串 P10）。
1. 先查中央氣象署有沒有颱風警報或特報（豪雨、強風、低溫等）。
2. 有警報或特報，就查人事行政總處與該縣市政府的停班停課公告，寫出公告時間。尚未公告就寫「截至 HH:MM 尚未公告」，不推測。
3. 官方頁讀不到就標 NOT_RETRIEVED，附官方連結請使用者自行確認；不得用新聞代替官方結論。
4. 之後才回答天氣細節與活動。有警報時推薦戶外活動或夜間演出，必須註明可能取消，請查主辦單位公告。
5. 交通：陸上颱風警報或強風特報期間，不建議騎乘兩輪車；優先大眾運輸，並查營運公告。

## 3. 輸出順序
第一段固定寫：警特報狀態（含發布時間）→ 停班停課（含公告時間或 NOT_RETRIEVED）→ 天氣 → 活動或交通建議。數字與狀態附行內標籤，最後一行寫流程鎖（同 miko-core §5 第 1、5 點）。
日期行寫在第一段之後、流程鎖之前（1.2.49）。引用的每個官方來源各寫一行日期「發布：YYYY-MM-DD｜生效：YYYY-MM-DD｜查閱：YYYY-MM-DD」，缺的寫 UNKNOWN，三項都要出現；警特報的發布時間、停班停課的公告時間接在同一行後面；讀不到（NOT_RETRIEVED）的來源也寫這一行，查閱寫本次日期，其餘寫 UNKNOWN，並在同一行寫「找過：官方頁網址（NOT_RETRIEVED）」（1.2.48；依 miko-core §4 與 references/research-and-dating.md，細節以本節為準）。

## 4. 檢查（驗收；2026-11-05 總檢補，正本 1.2.27。本 Skill 在正本 1.2.25 前採用，依 miko-core §2.4 不改判；「問問題」「後設」兩節與「解決」逐步閘門未補；1.2.43 加 §2 第 0 步、1.2.45 加 §2 開頭「凌晨說明天」、1.2.48 加 §3 日期行、1.2.49 寫明日期行位置時仍未補齊，依 skills/README.md 採用狀態表註記排在 tw-alert-check 升級站補齊）

- AC-W2：警報與停班停課的結論只來自 §1 白名單；官方頁讀不到標 NOT_RETRIEVED 並附官方連結，沒有用新聞或天氣網站代替。
- AC-W3：尚未公告時寫「截至 HH:MM 尚未公告」，沒有推測會不會停班停課。
- AC-W4：有警報時推薦的戶外活動或夜間演出，都註明可能取消、請查主辦單位公告。
- AC-W5：陸上颱風警報或強風特報期間，沒有建議騎乘兩輪車，改建議大眾運輸並查營運公告。

- AC-W7（1.2.43）：使用者說官方網站連不上時，對齊行之後先有七欄困難卡；本輪讀得到時解除條件寫「已解除（本輪取得成功，附證據）」（§2 第 0 步）。
- AC-W8（1.2.43）：同一機關兩頁不一致時，兩邊並列、附查閱時間、標 CONFLICT，沒有只取一邊（§1）。

- AC-W10（1.2.48）：引用的每個官方來源各有一行「發布｜生效｜查閱」，缺的寫 UNKNOWN，沒有把兩個來源合成一行（§3）。
- 實跑題：「明天颱風會不會停班停課？我要騎車去上班。」通過條件：AC-W1～W6 全過；官方頁讀不到的項目逐項標 NOT_RETRIEVED，不因讀不到就說「不會停班」。
