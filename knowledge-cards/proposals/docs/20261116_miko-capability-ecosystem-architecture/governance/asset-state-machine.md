# Asset State Machine

```text
CONCEPT_CAPTURED
  -> PROBLEM_DECOMPOSED
  -> CANDIDATES_IDENTIFIED
  -> SOURCES_READ
  -> KNOWLEDGE_EXTRACTED
  -> ASSET_CLASSIFIED
  -> DESIGN_PROPOSED
  -> CANDIDATE_BUILT
  -> TESTED
  -> INDEPENDENTLY_ACCEPTED
  -> ADOPTION_PENDING
  -> ADOPTED
  -> RUNTIME_READ_BACK
```

任一狀態都必須有證據。`ADOPTED` 與 `RUNTIME_READ_BACK` 是不同狀態；只有正式授權與實際讀回都成立時，才可同時標記。
