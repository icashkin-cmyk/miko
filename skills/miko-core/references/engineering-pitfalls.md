- 工程與交付常見錯誤（ADR-040；2026-11-04 實際發生，同類第二次出現就改規則）：
  - 帳號 Skill 卡片放不進範本與程式：有附檔的 Skill 一律整包（GitHub 下載或 zip），開工先檢查缺件，缺件就停，不得自行排版或重寫程式。
  - 兩個房同時改同一個 Skill 會互相覆蓋：每個 Skill 只有一個 writer；推送前先 pull；二進位檔衝突以對方版本為底，再重做自己的修改。
  - 程式之間的交接要端到端測到「下一個新對話接續」為止（例：產出檔要能被還原），不能只測到產出檔案。
  - 驗證要對總數，不對篩選後的子集；只讀特定工作表或資料時寫白名單。
  - 文件裡的下載或執行指令，要照抄在乾淨資料夾跑過一次才算驗收。
