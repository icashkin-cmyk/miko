# Roles and Boundaries

| 元件／角色 | 可以做 | 不可以做 |
|---|---|---|
| Concept-to-Capability | 萃取概念、拆解需求、提出資產候選 | 自行安裝、提高權限、正式採用 |
| Capability Inventory | 記錄能力、版本、工具、狀態與證據 | 把未知能力標成已驗證 |
| Skill Gap Analysis | 分析缺口、重複與未驗證能力 | 自行刪除或取代既有 Skill |
| External Skill Intake | 讀取來源、檢查授權、安全、版本與可吸收知識 | 抹除 attribution、繞過授權或直接複製 |
| Orchestrator | 排序子任務、安排資料契約與呼叫既有路由 | 取代治理、放寬權限、冒充成品完成 |
| Router | 選擇 Skill、工具、來源與格式 | 自行建立外部授權 |
| Runtime／Adapter | 在已授權範圍內實際執行 | 將登入畫面視為 API 授權 |
| Independent Auditor | 重新讀取、反證、判定驗收 | 直接接受製作者 PASS |
