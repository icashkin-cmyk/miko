# 美妝醫美專案包｜beauty-project v1.2｜2026-10-30
給 MIKO 開「美妝醫美」專案聊天室用。助理靠專案檔裡的產品清單知道你現在有什麼；GitHub 只放通用指令、範本與驗收題，不放個人資料。

## 檔案
| 檔案 | 用途 | 放哪裡 |
|---|---|---|
| INSTRUCTIONS.md | 專案指令全文 | 貼到專案的「指令」欄 |
| INVENTORY_TEMPLATE.md | 現有產品清單範本 | 填好後存成「美妝_現有產品.md」上傳到專案檔（不放 GitHub） |
| TESTS.md | 驗收題 P1～P8 | 專案建好後在新對話逐題問 |
| ../../skills/dghp-beauty/SKILL.md | 評估流程（六步） | Claude 帳號存 Skill 卡片；其他平台讀這個網址 |

## 建立步驟
1. 建專案，把 INSTRUCTIONS.md 全文貼進「指令」欄。
2. 建清單：最快的方法是把現有產品拍正面與成分面，丟進專案對話說「建立清單」，助理依範本產出 v1，你存成「美妝_現有產品.md」上傳到專案檔。
3. Claude 帳號存 dghp-beauty 卡片。
4. 開新對話跑 TESTS.md 的 P1～P8，全過才算可用。

## 維護
- 清單：每次「買了／用完／停用／換版」，助理輸出整份新清單（版本號加 1），你替換專案檔。清單只有你換，助理不自行寫入。
- 指令、範本、驗收題：由治理房改版並推送本 repo；改版時同步改 beauty-project 版本號與「對應 dghp-beauty」版本，tests/check_repo.py 的 C7 會檢查。
- 評估規則（六步、INCI 三態、醫美界線）只在 dghp-beauty 改，指令不另寫一套。

## 自動檢查
在 repo 根目錄執行 `python3 tests/check_repo.py`。C7 檢查：四個檔都在、版本號一致、指令對應的 dghp-beauty 版本和 Skill 標題相同、範本表格與膚況欄位沒有填入資料、驗收題 P1～P8 都在。C8 檢查：repo 裡沒有「美妝_現有產品.md」或「*_個人資料.md」這類個人檔（.gitignore 也已排除）。
