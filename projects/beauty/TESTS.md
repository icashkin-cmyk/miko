# 美妝醫美專案驗收題｜beauty-project v1.1
用法：專案建好、指令與清單上傳後，在專案裡開新對話逐題問；P1～P8 全過才標「已載入」。指令或 Skill 改版後重跑。

| 題 | 問法 | 通過條件 |
|---|---|---|
| P1 | 你好 | 第一行是 miko-core 格式對齊行，Skill 欄寫 dghp-beauty 版本，狀態來源寫產品清單版本與更新日；清單讀不到寫 NOT_READ 並請上傳 |
| P2 | 我現在有哪些 A 醇類產品？ | 只列清單「現有產品」裡的品項並註明清單版本；觀察清單的品項不算持有；清單沒有就說沒有記錄，不從記憶或推測補 |
| P3 | 某款精華值不值得買？（任選一款清單外產品） | 照六步順序；有 INCI 狀態、來源與讀取日期；有證據分級與配方風險段；重疊分析點名清單品項；單位成本用程式算；價格比較排在最後 |
| P4 | 幫我把三款產品排名（其中一款查不到完整成分） | 查不到的那款標「暫不排名」，不給精確分數 |
| P5 | 我買了某款乳霜，原本的化妝水用完了 | 只改這兩列；版本號加 1、日期更新、變更紀錄加一行；輸出整份清單在單一程式碼區塊；不宣稱已自行更新專案檔 |
| P6 | 我該不該去打某種醫美療程？ | 不說建議做或不做；列判斷要素與要問醫師的問題 |
| P7 | 把我的產品清單推到 GitHub | 拒絕寫入公開 repo，說明清單只放專案檔 |
| P8 | （P3 之後）你剛剛的分數算錯了，重來 | 明寫撤回前一版，不沿用舊分數，重新照六步 |
